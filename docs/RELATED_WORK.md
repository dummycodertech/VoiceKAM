# Related Work & Design Context

VoiceKAM sits at the intersection of tool-augmented reasoning agents, factual grounding verification, and browser-native speech interaction:

1. **Tool-Augmented Reasoning (`ReAct` — Yao et al., 2022, [arXiv:2210.03629](https://arxiv.org/abs/2210.03629)):** Demonstrates interleaving LLM reasoning traces with grounded environment/tool observations. VoiceKAM extends this idea for low-latency voice calls by moving mandatory diagnostic tool selection to deterministic server pre-execution in `DIAGNOSE` and `RECOMMEND` turns rather than spending multi-round LLM tokens to discover read-only analytics.
2. **Structured API / Tool Calling (`Toolformer` — Schick et al., 2023, [arXiv:2302.04761](https://arxiv.org/abs/2302.04761)):** Establishes lightweight model invocation of deterministic calculators and lookup APIs to overcome arithmetic errors. VoiceKAM delegates 100% of GMV, velocity, pricing DiD, and cancellation math to Python tools in `app/engine/diagnosis.py`, limiting free-tier LLM responsibilities to empathetic explanation and slot capture.
3. **Atomic Factual Verification (`FActScore` — Min et al., 2023, [arXiv:2305.14251](https://arxiv.org/abs/2305.14251)):** Motivates decomposing model responses into verifiable claims checked against trusted sources. VoiceKAM implements a fast numeric specialization of this check (`find_ungrounded_numbers()` in `app/agent/speakable.py`) that verifies every spoken digit token against `session.grounded_numbers` collected from deterministic tools in real time.
4. **Browser Voice Capture & Synthesis (`Web Speech API` — W3C Speech API Community Group, [webaudio.github.io/web-speech-api](https://webaudio.github.io/web-speech-api/)):** Defines standard `SpeechRecognition` and `speechSynthesis` browser primitives used by VoiceKAM's client audio pipeline alongside end-of-utterance debouncing, half-duplex speaker echo gating, and optional Whisper/Edge-TTS fallbacks.
5. **Distinctive Contribution:** While generic BI copilots focus on open-ended SQL generation over text chat and commercial voice agents prioritize booking or FAQ deflection, VoiceKAM pairs **causal counterfactual attribution (with explicit residuals and missing-column honesty)**, **server-enforced phase & numeric grounding**, and **multilingual `en-IN` / `hinglish` / `hi-IN` speakable telemetry** inside a zero-database, free-tier deployable architecture.
