Three steps, one conversation

  1. 01You talk

    Describe the problem in plain words. The agent asks only the few questions the data can't answer.

  2. 02It checks the data

    Stock-outs, price gaps, visibility and cancellations are computed in code. The language model never does the arithmetic.

  3. 03You commit

    Pick actions, set dates, get a written summary, then a follow-up call checks what moved.

What it does not claim

  • The stores are synthetic. Attribution is validated against planted causes, not real marketplace data.
  • The number audit checks that spoken figures appear in the tool results. It flags mismatches; it does not prove every figure is used correctly.
  • Free hosting sleeps when idle, so the first request can take about a minute.
  • Live speech input needs Chrome or Edge. Do not upload real or confidential seller data.
